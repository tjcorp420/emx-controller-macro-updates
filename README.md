# EMX Controller Macro updates

Official distribution repository for EMX Controller Macro.

This repository is reserved for compiled release downloads and signed update metadata. Application source code, private signing keys, customer data, and license credentials are not stored here.

A paid EMX Controller Macro entitlement is required to enable macros. Downloading an update does not grant a license.

Production downloads are available under Releases. Existing apps use the signed update.json feed.

For 0.7.0, the recommended controller-only layout is L3 activation, Touchpad Edit and Left D-pad Select. Users must clear conflicting Left D-pad actions in Fortnite before applying it. Existing profiles are preserved; custom Select buttons can still trigger non-edit actions when an edit is not active.

Visit https://controller.emxtweaks.com for product information.

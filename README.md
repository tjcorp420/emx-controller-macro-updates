# EMX Controller Macro updates

Official distribution repository for EMX Controller Macro.

This repository is reserved for compiled release downloads and signed update metadata. Application source code, private signing keys, customer data, and license credentials are not stored here.

A paid EMX Controller Macro entitlement is required to enable macros. Downloading an update does not grant a license.

No production release is available yet. Visit https://emxtweaks.com for product information.
